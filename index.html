📱 Panduan Install

🤖 Android (Chrome)

  1. Buka aplikasi di Chrome
  2. Klik menu ⋮ (titik tiga) di pojok kanan atas
  3. Pilih "Add to Home screen"
  4. Klik "Add" / "Install"
  5. Icon muncul di home screen!

🍎 iOS (Safari)

  1. Buka aplikasi di Safari
  2. Klik tombol Share (kotak dengan panah)
  3. Pilih "Add to Home Screen"
  4. Klik "Add"
  5. Icon muncul di home screen!

💡 Aplikasi akan berjalan fullscreen seperti native!
